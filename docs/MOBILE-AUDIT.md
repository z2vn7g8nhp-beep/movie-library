# 手机端体检 & 怎么把它做成艺术品

> 全部结论都是在真机尺寸的无头 Chrome（390×844 @2x，iOS 安全区 47/34pt，中文字体齐全）里跑出来的，
> 不是看代码猜的。截图在 `screens/`：
> `mobile-before-after-home.png` 左旧右新并排（看图标、留白、字的灰度）；
> `mobile-before-after-lib.png` 是同一块区域上下叠放放大（片库这一轮改动小，并排看不出来）。

---

## 一、先说结论

影库的**内容**已经很奢侈了（26 个手写宇宙、卡面稀有度、年报、痛柜……），
但**手机端的外壳**还是「一个做得很漂亮的网页」。差的是这三件事：

| | 现在的感觉 | 该有的感觉 |
|---|---|---|
| 手感 | 按钮 36px，点起来要瞄准；长按会选中文字 | 44pt 起，按下去有回应，不会误选 |
| 字体 | 手机上没装宋体时，标题变细黑体或（安卓）直接豆腐块 | 标题有笔锋，正文任何设备都不缺字 |
| 密度 | 片库一年一部也占一整屏（这个**没动**，见第二节 4） | 有东西的地方才占地方 |

这一轮把**手感**和**字体**做掉了，密度里那条「滚动条虚高」的 bug 也修了，但
「稀疏年份占一整屏」这件事我试过三种改法，全都不好看，**主动放弃了**（理由在第二节 4，
我不建议你再走一遍）。顺手换了图标、主题色、启动体验。
再往下走就是「艺术品」那一层（第四节），那部分需要你定方向。

## 二、体检报告（实测数字）

### 1. 触控目标

| 元素 | 改前 | 改后 |
|---|---|---|
| 顶栏月亮 / 搜索 / 设置 | 36×36 | 44×44 |
| 片库筛选标签 chip | 30 高 | 34 高 + 44 的透明落点 |
| 底部导航 | 48 高但 10.5px 字，`--faint` 色 | 48 高、11–12px、`--ink-2` 色 |
| 「全部 / 更多 / 清空」这类小链接 | 20 高 | 视觉不变，落点 44 |
| 片库「按年份排序」 | 24 高 | 落点 44 |

页面里还有 11 处 < 44pt 的可点元素（片名行、类型标签、`修改评分`、`加入片单`、
`在豆瓣搜` 等），它们大多是**行内文字链接**，直接加高会破坏版面，
所以用 `::after` 把可点区域撑到 44（第三节代码里那段）。

### 2. 对比度（WCAG AA 要 4.5）

| token | 改前 | 改后 |
|---|---|---|
| `--dim` 在 `--bg` 上 | **2.78** ❌ | **4.97** ✅ |
| `--faint`（描边、分隔、星星底槽） | **1.57** | 2.53 —— 只做装饰，**所有文字已改用 `--dim`** |
| `--acc-ink`（粉色强调小字） | 4.19 ⚠ | **5.50** ✅ |
| `--gold-ink`（金色小字标题） | 3.68 ❌ | **5.11** ✅ |
| `--wish / --doing`（想看 / 在看） | 2.42 / 2.81 ❌ | **4.75 / 5.24** ✅ |
| 夜间 `--dim` | 5.40 ⚠ | **6.98** ✅ |
| 夜间 `--faint` | 2.65 ❌ | **4.67** ✅ |

这是手机上最影响「贵不贵」的一条：把灰度提上去，浅色那条晨雾底立刻从「淡到发虚」变成「淡但清楚」。

### 3. 字体（真机上最容易翻车的一项）

- 标题用的是 `Songti SC`（只在苹果有）。**安卓没有宋体**，`STSong` / `Noto Serif CJK`
  多数国产 ROM 也没装 → 标题掉到系统黑体，影库那种「香槟金 + 宋体」的调子当场消失。
- 用 `CSS.getPlatformFontsForNode` 实测：`.hero h2` 在无宋体环境下落到 DejaVu（豆腐块），
  也就是说**同一份网页在不同手机上长得完全不一样**。
- 解决：把界面标题、按钮、导航会用到的 **104 个汉字**做成两个 20KB 的宋体 woff2（600 / 900），
  `preload` + `font-display:swap`，只用在 `.top h1`（影库）和页脚落款上。
  片名、人名这些字不可预知，继续走系统字体 —— **缺字只会掉回系统宋体，不会变方块**。

### 4. 密度与空白（片库最明显）

改前：9 部片子滚动高度 3057px ≈ 3.6 屏，因为「按年份」分页时每年只有 1 部也占满一整块网格。

**这里我一开始报错了，先更正**：我试过把稀疏年份改成横排小胶片（96px / 104px 两版都做了），
截了 7 轮图，结论是**更碎、更乱，已经整体回退**（`.bfew`、`.bpage-fi`、`smallCard` 全部删干净，`binderHTML` 恢复原样）。
中途我量到 2349px 就写进了报告，那是**测量方式错了**，不是真实收益 —— `.b-page` 上有
`content-visibility:auto`，滚动时浏览器用 `contain-intrinsic-size` 的占位值（当时写的是 600px）去顶替
还没排版的分页，`body.scrollHeight` 因此虚高 700 多 px。把占位关掉重测：

| | 改前 | 改后 | |
|---|---|---|---|
| 片库**真实排版**高度（`content-visibility` 关掉后）| 2669px | **2712px** | +43px，来自 `.mt`/片名/导航字号各 +0.5~1px 的可读性调整 |
| 片库**滚动总高**（浏览器实际看到的）| 3057px | **2746px** | **−311px（−10%）** |
| 首页滚动总高 | 1751px | 1744px | 基本持平 |

也就是说：**页面没有变短，是「假装变短」的 bug 被修了**。`contain-intrinsic-size` 从 600px 改成实测
一页 250px 之后，滚动条长度终于和真实内容对得上 —— 好处是滚动位置不会在排版完成后突然跳、也看不到
底部一大片空白。真正的密度优化（稀疏年份）我已经放弃，理由见上：卡册的大卡是它的卖点。

如果你以后还是想要更短，可选项见第五节 B 组。

### 5. 性能

| 指标 | 实测 |
|---|---|
| 首屏 HTML | 491KB（单文件，gzip 后约 90KB）|
| CSS 规则数 | 1679 条（其中有几层 v3→v7 的历史覆盖）|
| `backdrop-filter` | 3 处（顶栏 / 底栏 / 弹层），低端安卓会掉帧 |
| 索引 | 12.7 万条，分两份 + 分片按需取，首份解析完就有结果 —— 这块做得很好，别动 |
| 滚动容器 | `.b-page` 有 `content-visibility:auto` ✅ |

### 6. 其它已经修掉的小毛病

- `theme-color` 写的是 `#F3F4F8`，实际底色是 `#F8F5FC` → 状态栏和页面差一档，现在跟主题一起变。
- 没给豆瓣图床 preconnect（海报一半来自豆瓣）→ 已补 4 个。
- 输入框聚焦时底部导航会盖住输入框 → 键盘弹出时导航先让开（`visualViewport`）。
- 首页四个入口用的是 emoji（🎀🗓📜），不同手机长得不一样，有的还是空心方块 → 换成线性图标。
- 长按海报会弹出「拷贝图片 / 存储图片」，像网页 → 卡片区域关闭长按菜单和选取。
- 桌面打开是拉满全宽的手机版 → ≥720px 收成 560px 的版心。
- 「减少动态效果」只覆盖了 3 处动画 → 补齐页面切换、卡片弹出、键盘让位。

## 三、这一轮改了什么（都在 `docs/`）

```
docs/index.html
  ├─ 触控：icon-btn 44px、chip 34px + ::after 落点、小链接 44 落点、.btn min-height 44
  ├─ 对比度：--dim / --faint / --wish / --doing / --acc-ink / --gold-ink（日间 + 夜间各一组），
  │          并把 12 处误用 --faint 的小字（导航未选中、评分缺失、徽章说明…）统一改成 --dim
  ├─ 视口：去掉 maximum-scale=1（WCAG 1.4.4，允许双指缩放）、100vh → 100dvh、
  │         @media (display-mode:standalone) 顶部多留 8px
  ├─ 性能：backdrop-filter 包进 @supports（不支持就直接用不透明底，不掉帧）；3 处减到 3 处但都可降级
  ├─ 滚动：.b-page 的 contain-intrinsic-size 600px → 250px（实测一页高度，见第二节 4）
  ├─ 字体：@font-face "Yingku Song" ×2（各 20KB）+ preload + 只给 .top h1 / .fin b 用
  ├─ 窄屏：@media ≤430 / ≤340（--pad、导航字号、筛选一行放下、字号阶）
  ├─ 手感：user-select / touch-callout / -webkit-user-drag 关闭、overscroll-behavior 收边、:active 反馈
  ├─ 键盘：html.kb-open 让底部导航退场 + 输入框滚进视野
  ├─ 桌面：≥720px 版心 560
  ├─ 主题：theme-color / color-scheme 跟着昼夜切换
  └─ 入口图标：emoji → 线性 SVG
docs/fonts/head-600.woff2, head-900.woff2   ← 新，各 20KB，只含界面用字
docs/icon-180/192/512.png, icon-maskable-512.png ← 新图标（见下）
docs/manifest.json  ← id / display_override / orientation / maskable / 描述
docs/sw.js          ← shell cache v17（老用户会拿到新图标、新字体、新配色）
docs/screens/*.png  ← 改前 / 改后对比（390×844@2x，中文字体已注入）
```

### 新图标

旧的是一张「三张彩色卡片 + 影库」的插画，在 iOS 桌面上会被裁成圆角、
和现在的紫金界面也不是一个色系。新的：

- 夜空底色（就是夜间主题的 `#17132A → #3B2C63`）+ 香槟金星屑；
- 三张卡（原图标的三色）保留成「一手牌」，中间那张带胶片孔；
- 「影库」用自带的宋体 900 压成金色，下面一行 `CINEMATHEQUE`；
- 另外导出一版 **maskable**（四周留 6% 安全区），安卓桌面不会是切掉一圈的方块。

## 四、怎么把它做成「艺术品」

「艺术品」不是再加装饰，而是**让整个 App 只有一种材质、一种节奏、一种笔迹**，
然后让内容（你的观影史）成为唯一的画面。按性价比从高到低：

### 1. 一个真正的「作品页」（现在最弱的一屏）

条目页现在还是「海报 + 三个评分 + 按钮 + 演职员」的豆瓣结构。艺术品版本：

```
全屏海报（缓慢 Ken Burns 3% 缩放，只在可见时跑）
  ↓ 海报底部 12% 处，标题压在海报上（宋体 900，像电影片头字卡）
  ↓ 滚动时海报渐隐，标题缩进顶栏（共享元素过渡）
一张「票根」：你的评分 / 那次观看的日期 / 当时的短评（手写体）
一段「放映机」：剧照一条横胶片，左右滑动像倒片
```

一张页面里只出现一个「大字」和一条「金线」，其余全是灰阶 —— 奢侈感来自留白，不是来自数量。

### 2. 卡面收集 → 真正的卡牌工艺

现在卡面已经有稀有度边框、holo、签名。再走一步：

- **浮雕**：UR 卡的边框用 `filter: drop-shadow` + 极细内高光做出金属倒角（现在只有渐变）。
- **倾斜跟随**：手指按住卡片时按指尖位置移动 holo（`--hx/--hy` 已经有了，只差 `pointermove`）。
- **开包仪式**：卡包撕开 → 卡片从暗到亮、稀有度越高停顿越久（现在是统一的 pop）。
- 这三件事都只在 `will-change` + `transform` 里做，12 张卡同屏也不掉帧。

### 3. 版式系统：三档字号 + 一条栏宽

现在有 26 种字号、5 种圆角、4 套阴影。艺术品需要**唯一性**：

```
标题 28/900 宋体 · 小标题 17/700 宋体 · 正文 15/400 黑体 · 注脚 12/400 灰
圆角只有 3 档：卡 18 / 图 10 / 胶囊 999
金色只用于「值得看一眼」的东西：稀有度、分数、金线
```

把它写进 `:root` 的 token，以后所有新功能只许用 token，页面自然就统一了。

### 4. 动效：只做「有意义的三下」

- 页面进入：从右侧推入 36%（现在有，但 0.28s 偏慢）→ 0.22s + `cubic-bezier(.2,.9,.2,1)`。
- 标记完成：印章盖下（现在有）+ 一条极细的金色扫光从标题划过 1 次。
- 数字：年报 / 统计的大数字做 `countUp`（0.8s），别的都不动。

**不做**：无限旋转、闪烁、粒子。手机上一切常驻动画都是耗电和掉帧。

### 5. 声音（可选，但很「作品」）

- 盖章：一段 80ms 的纸声；开包：300ms 的撕纸 + 一记很轻的铃。
- 默认关闭，设置里「拟音」开关；用 WebAudio 合成，不下载音频文件。

### 6. 年报 → 一本可以翻的小画册

现在年报是一屏数据。改成 **6 页**、横向翻页（`scroll-snap`）、每页一个主题：
最常看的导演、你的类型指纹（雷达图）、今年的第一次和最后一次、点亮最多的宇宙、一句话总结。
最后一页是分享图 —— 你现在的分享图已经是 canvas 画的，把年报的排版复用到 drawImage 里就能出书。

### 7. 语音 & 文字：让「影库」说话

角色聊天（乙女模式）已经有现成的 `chat.js`。加一层：

- 点开角色档案，第一句话用 `SpeechSynthesis` 读出来（中文音色系统自带）。
- 打分开封的「本命」贴纸，说一句角色台词。
- 这个功能对 GPU 零成本，但对「艺术品」这件事的加分非常高。

### 8. 最后一件事：删

- 首页现在有：卡组、收藏册、入口一排、在看、最近看过、想看、常看的影人、类型、标签、页脚 —— **10 块**。
- 艺术品版本只留：**卡组 → 在看 → 最近看过**，其余收进一个「更多」。
- 「少」是最贵的装饰。这一条如果只做一件，做这件。

## 六、复现这份体检

体检脚本没有进仓库（它依赖本地字体和截图工具，属于开发脚手架）。
核心做法，任何人都能复现：

```js
// 在 390×844 @2x、安全区 47/34 的页面里
document.querySelectorAll('a,button,[onclick],[role=link]').forEach(el => {
  const r = el.getBoundingClientRect();
  if (r.width && r.height && (r.width < 44 || r.height < 44)) console.log(el, r.width, r.height);
});
// 对比度：把 :root 的 token 取出来，按 WCAG 公式算一遍（--dim 从 2.78 → 4.63）
// 字体：CDP CSS.getPlatformFontsForNode —— 看实际渲染用了哪套字形
```
